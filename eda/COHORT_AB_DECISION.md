# 코호트 A안 / B안 — 랩미팅 결정 요청

**정해달라는 것: 첫 24시간에 이미 섬망(CAM Positive)인 환자 7,985명을 코호트에서 뺄 것인가.**

우리끼리 정할 수 없는 이유: 이건 데이터 문제가 아니라 **"무엇을 예측할 것인가"** 문제다. 양쪽 다 계산해 두었다.

---

## 0. 공통 — 여기까지는 이견 없음

```
94,458  전체 ICU stay
   ↓ ① 성인 (age>=18)                          94,458   (이 DB의 ICU는 전부 성인)
   ↓ ② 환자당 첫 ICU stay만                     65,366
   ↓ ③ ICU LOS >= 24h                          51,838   ← 여기까지가 base3
   ↓ ④ 관찰창 = 입실 후 첫 24h                  (필터 아님, 정의)
   ↓ ⑤ ★첫 24h CAM Positive 제외?              ← A안/B안이 갈리는 지점
   ↓ ⑥ 결과창에 판정 기록이 있어야
   ↓ ⑦ 라벨 = 결과창 내 Positive >=1
```

**결과창은 24–72h 고정을 권장한다** (아래 §3). 이 결정은 A/B와 **독립**이다.

---

## 1. A안 vs B안

| | **A안 — 제외** | **B안 — 포함** |
|---|---|---|
| ⑤ 적용 | 첫 24h Positive 7,985명 **제외** | **포함** |
| 분모 | 43,853 | 51,838 |
| 라벨 부여 stay | **22,867** | **29,500** |
| **섬망 유병률** | **15.6%** | **25.6%** |
| 라벨=1 사망률 | 17.2% | 18.8% |
| 라벨=0 사망률 | 4.8% | 5.2% |
| 관찰기회 편향 | 2.8배 | **2.8배 (동일)** |
| **예측하는 것** | **섬망이 새로 생기는가** | 24–72h에 섬망 상태인가 |

### B안에서 추가되는 6,633명의 성격

| 항목 | 값 |
|---|---:|
| 추가 stay | 6,633 (B안 라벨부여의 22.5%) |
| 그중 라벨 Positive | **60.2%** |
| 사망률 | **15.4%** |
| (참고) A안 집단 사망률 | 6.7% |

**위중한 지속군이 통째로 들어온다.** B안의 라벨=1은 "새로 생긴 섬망"과 "첫 24h부터 이어진 섬망"이 섞인다.

---

## 2. ⑤의 원래 근거가 데이터로 흔들린다

⑤의 논리는 "이미 섬망이면 *발생*을 예측할 수 없으니 제외"였다. 실제로 확인한 결과:

| 제외 대상 7,985명의 이후 경과 | |
|---|---:|
| 첫 P 이후 **Negative로 회복** | **81.7%** (median 19.7h) |
| 회복자 중 **다시 Positive (재발)** | **46.3%** (median 12.6h) |
| 24h 이후 계속 Positive만 | 7.5% |

**"한 번 걸리면 끝"이 아니라 왔다갔다 한다.** 영구 제외의 전제가 약하다.
→ 제3안(회복 확인 후 risk set 재진입)도 논리적으로는 가능하나, 구현 복잡도가 크게 오른다.

---

## 3. 결과창 — 24–72h 고정 (A/B와 독립인 별도 결정)

**기존 "24h 이후 퇴실까지"는 섬망이 아니라 재원기간을 재고 있었다.**

| 결과창 내 판정 횟수 | 기존(24h~퇴실) | **24–72h 고정** |
|---|---:|---:|
| 1회 | 5.1% | 8.7% |
| 2회 | 8.3% | 13.8% |
| 3–4회 | 14.4% | 18.8% |
| 5회+ | 27.9% | 24.3% |
| 17회+ | 76.3% | — |
| **최대/최소 비** | **26배** | **2.8배** |

오래 누워 있으면 평가를 많이 받고, 많이 받으면 언젠가 한 번은 양성이 나온다. 고정 창이 이걸 대부분 없앤다.

**대가 — 결과창에서 관찰 못 하는 stay가 47.9%다 (⑤통과 43,853 기준):**

| 사유 | stays | 비중 |
|---|---:|---:|
| 72h 이전 ICU 퇴실 | 14,221 | 67.8% |
| 재원 중 기록 없음 | 4,415 | 21.0% |
| 재원 중 전부 UTA | 1,274 | 6.1% |
| 72h 이전 사망 | 1,076 | **5.1%** |

**사망은 5%뿐**이라 경쟁위험(competing risk)보다 **조기 퇴실**이 주 탈락 사유다. 72h 안에 나간 환자는 애초에 섬망 위험이 낮은 군이라, informative censoring이긴 하나 사망만큼 심각하지 않다.

## 4. 같이 정해야 할 부수 결정 3개

| 쟁점 | 숫자 | 선택지 |
|---|---|---|
| **진료과 제한** | 섬망률이 CVICU 19.8% ~ NeuroSICU 55.3% 로 갈림 | 전체 ICU / **MICU 계열**(MICU+MICU/SICU) |
| **시기 컷** | 2008–2010은 섬망평가 차팅 44%뿐 | **≥2011** 권장. 투약 변수 쓰면 ≤2019 (2020–22 inputevents 41.5%) |
| **UTA 처리** | UTA 21.9%, 그중 78%가 RASS≤−4 | 제외 / 별도 상태 + masking / **LNN 구간 진리값** (분기 규칙상 LNN) |

⚠️ **UTA-only 집단(1,049명)의 병원 사망률이 81.7%다.** 어느 안을 택하든 이들이 빠지므로, 결과 보고 시 **"사망 직전 환자를 제외한 집단에서의 성능"**이라고 명시해야 한다.

## 5. 새 데이터가 코호트에 미치는 영향

**mimic-iv-ed 는 코호트 조건으로 넣지 않는다.**

| 대상 | ED 연결률 |
|---|---:|
| delirium 코호트 | **42.7%** (10,222 / 23,939) |
| CVICU | 14.1% (예정수술이라 응급실 안 거침) |
| 2020–2022 | 0.0% (ED 데이터 수집 기간 밖) |

필수로 요구하면 코호트가 57% 날아가고, 그것도 **CVICU·심장계열이 통째로 빠지는 편향된 손실**이다.
다행히 ED 유무가 결과를 왜곡하진 않는다 (섬망률 23.1% vs 22.0%, 사망률 7.7% vs 7.1%).
→ **ED 변수는 "있으면 쓰는 보조 변수", 없으면 결측 처리.**

**mimic-iv-note 도 코호트 조건으로 넣지 않는다.** 연결률은 ED보다 훨씬 높다:

| 대상 | discharge | radiology |
|---|---:|---:|
| 전체 (adult, LOS≥1d) | **76.3%** | 74.7% |
| delirium 코호트 | **72.8%** | 70.4% |

규모: discharge 331,793건(median 9,847자), radiology 2,321,355건.

⚠️ **노트 결측이 무작위가 아니다.** 노트 없는 환자가 더 위중하다:

| | 노트 있음 (17,433) | 노트 없음 (6,506) |
|---|---:|---:|
| 섬망률 | 21.1% | **26.1%** |
| 사망률 | 6.7% | **9.1%** |

→ 동반질환을 노트에서 뽑아 결측을 0으로 채우면 **위중한 환자 쪽이 체계적으로 0이 된다.** 원 논문이 23개를 전부 0으로 둔 것과 같은 방향의 편향이므로, 재현 결과에 반드시 명시한다.

단 `discharge` note는 퇴원 시점 작성이라 **예측 입력으로 쓰면 leakage** — 입원 이전부터 있던 정보(동반질환)만 뽑아 쓴다.

### 2020–2022는 새 데이터 둘 다 없다

| 시기 | ED | discharge | inputevents |
|---|---:|---:|---:|
| 2008–2010 | 27.1% | 87.2% | 96.6% |
| 2011–2013 | 45.7% | 87.6% | 96.2% |
| 2014–2016 | 52.0% | 87.8% | 95.9% |
| 2017–2019 | 48.7% | 82.6% | 94.8% |
| **2020–2022** | **0.0%** | **0.0%** | **41.5%** |

→ **시기 상한을 2019로 두는 근거가 하나 더 늘었다.** 권장 구간은 `2011–2019`.

## 6. 우리 권고

```
결과창    24-72h 고정                    (근거 확실, A/B와 독립)
시기      anchor_year_group >= 2011      (2008-2010 차팅 부족)
진료과    MICU + MICU/SICU               (섬망률 편차가 너무 큼)
UTA       별도 상태로 보존 + LNN 검토     (분기 규칙 트리거)
ED        보조 변수만                    (연결률 42.7%)

⑤ 첫 24h Positive 처리 → 결정 요청
   A안 권장: "새로 생기는 섬망 예측"이 임상적으로 유용하고
             (예방 개입 가능) 교란도 가볍다.
   단 ⑤의 전제(영구 제외)가 데이터로 약해졌으므로,
   B안을 민감도 분석으로 같이 보고하는 방식도 가능하다.
```
