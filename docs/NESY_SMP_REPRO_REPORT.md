# NeSy-SMP 논문 재현 보고

> 작성 2026-09-16 · 대상 논문: De Santis 외, *Neuro-symbolic artificial intelligence for real-time sepsis mortality prediction*, Engineering Applications of AI 177 (2026)
> 이 문서는 **논문에 적힌 조건 그대로 다시 한 재현만** 다룬다. 그 전에 조건을 바꿔 가며 돌린 실험들은 포함하지 않는다.
> 상태: 학습 진행 중 — 6h 결과는 중간값(5개 중 3개 fold), 12·24·48h 는 대기 중

---

## 한 줄 요약

논문에 적힌 방법대로 환자를 고르고, 임상노트에서 지병을 뽑고, 원저자가 공개한 코드로 학습하고 있다.
**중간 결과로는 모든 모델이 논문보다 AUC 가 2~4점 높고, 논문이 주장한 "NeSy-SMP 가 가장 좋다"는 아직 재현되지 않는다.**
또 **원저자가 공개한 코드는 그대로 돌리면 중간에 오류로 멈춘다** — 최소한으로 고쳐서 돌렸다.

---

## 1. 어떤 연구인가

- 중환자실 패혈증 환자가 **병원에서 사망할지**를 미리 예측한다.
- 사망 6·12·24·48시간 전까지의 **24시간 기록**(혈압·심박수·검사 수치 등)을 보고 맞힌다.
- 비교하는 모델 5개
  - **RF · XGBoost** — 수치를 요약해서 쓰는 전통적인 방법
  - **BiLSTM** — 시간 순서대로 읽는 딥러닝
  - **LTN** — 딥러닝 + 논리 틀
  - **NeSy-SMP** — LTN 에 "젖산이 높으면 위험하다" 같은 **의학 지식 규칙**을 넣은 것 (논문이 제안한 모델)

## 2. 어떻게 재현했나 — 원칙

1. **논문에 적힌 대로** 한다.
2. 논문에 안 적혀 있으면 **원저자 공개 코드대로** 한다.
3. 둘 다 없으면 **MIMIC 데이터 공식 계산 코드**(mimic-code)를 따른다.
4. **논문 숫자에 맞추려고 기준을 바꾸지 않는다.**

### ② 지병(동반질환) 뽑기
- 논문: "퇴원기록의 **현재 병력(HPI)** 과 **과거 병력(PMH)** 부분에서 뽑았다"
- 원저자 공개 코드의 규칙(암·당뇨·고혈압 등 23개 질환 단어 찾기, 부정·가족력 제외)을 그대로 쓰고, 논문대로 **두 부분에서만** 찾았다.
- 퇴원기록 52,488건 처리 · 우리 환자 중 91.2% 가 퇴원기록이 있음
- ⚠️ 결과가 적게 나온다 — 지병이 하나라도 잡힌 환자 30.3%, 고혈압 6.9%. 원문대로 한 결과라 그대로 쓴다.

### ③ 쓸 기록 뽑기 (논문에 적힌 변수만)
- **고정 정보**: 나이, 입원 경로
- **바이탈**: 수축기·이완기·평균 혈압, 체온, 심박수, 호흡수
- **혈액 검사**: 크레아티닌, 헤모글로빈, 혈소판, 빌리루빈, 칼륨, 알부민, CRP, 혈당, 젖산, 림프구, 호중구, 백혈구, ALT, AST
- **의식 점수**: GCS
- 중환자실에 있던 동안의 기록만 · 총 2,283만 건

- **사망한 환자**: 사망 N시간 전(6·12·24·48h)까지의 기록 중 **마지막 24시간**
- **살아난 환자**: 중환자실에 있던 기간 중 **아무 24시간**

| 24시간 전 | 26,125 | 14.7% |

(더 이른 시점일수록 그 전에 기록이 없는 사망 환자가 빠진다)

### ⑤ 학습 — 원저자 공개 코드 그대로
- 환자를 5묶음으로 나눠 **5번 돌리고 평균** (매번 1묶음은 시험용, 나머지의 20% 는 검증용)
- 딥러닝 50번 반복, LTN·NeSy-SMP 20번 반복 (공개 코드 기본값)
- 지식 규칙: 공개 코드에 적혀 있는 규칙 그대로 (의식 저하, 젖산 상승, 혈소판 감소, 빌리루빈 상승, 호흡·혈압 이상, 크레아티닌, CRP, 만성질환, 백혈구, 고령 등)
- 성적: 정확도 · F1 · AUC

## 4. 원저자 코드에서 고친 것 — 5군데

돌아가게 하는 데 **꼭 필요한 것만** 고쳤다. 계산 방법은 바꾸지 않았다.

| | 무엇 | 왜 |
|---|---|---|
| 1 | 입력 파일 경로를 바꿀 수 있게 | 원래 한 파일 이름이 고정돼 있음 |
| 2 | 묶음별 성적도 저장 | 원래 평균만 저장 |
| 3 | 약물 항목이 없을 때 안내 문구 건너뛰기 | 논문 변수에 약물이 없는데, 없으면 오류로 멈춤 |
| 4 | 규칙 모델 입력 크기 자동 계산 | 원래 숫자를 손으로 바꿔 넣게 돼 있음 |
| 5 | RF·XGBoost 입력 계산 순서 | **공개 코드 그대로 돌리면 첫 묶음에서 오류로 멈춤** (평균을 먼저 구한 뒤 그 평균으로 편차를 구하려 함) |

→ **5번은 중요한 발견이다. 공개된 코드로는 논문 결과를 만들 수 없다.** 저자가 실제로 쓴 코드는 공개본과 달랐다는 뜻이다.

## 5. 결과

### 사망 6시간 전 예측 — 🔄 중간값 (5묶음 중 3묶음 평균)
| 모델 | 정확도 (논문 / 재현) | F1 (논문 / 재현) | AUC (논문 / 재현) |
|---|---|---|---|
| RF | 84.78 / 90.71 | 74.77 / 76.65 | 88.11 / 90.93 |
| XGBoost | 85.31 / 91.56 | 77.86 / 81.54 | 88.56 / **92.74** |
| BiLSTM | 83.53 / 90.52 | 76.82 / 80.30 | 85.35 / 89.55 |
| LTN | 85.65 / 91.03 | 79.20 / 81.62 | 88.10 / 90.95 |
| **NeSy-SMP** | **86.45** / 90.77 | **80.35** / 81.28 | **88.33** / 90.75 |

지금까지 보이는 것:
- **모든 모델이 논문보다 높다** (AUC +2~4점, 정확도 +4~7점).
- **논문과 순서가 다르다.** 논문은 NeSy-SMP 가 가장 좋았지만, 재현에서는 XGBoost 가 AUC 가장 높고 NeSy-SMP 는 규칙 없는 LTN 과 비슷하다.
- 아직 3묶음이라 확정은 아니다.

## 6. 논문과 여전히 다른 점

| 무엇 | 왜 못 맞췄나 |
|---|---|
| 환자 수 26,251명 · 사망률 15.1% (논문 19,328명 · 18%) | 논문의 "데이터 없는 환자 제외" 기준이 구체적으로 안 적혀 있음 · 데이터 버전이 다름 |
| 데이터 버전 (논문 v2.2, 우리 v3.x) | v2.2 원본이 없어 연도로 잘라 비슷하게 맞춤 |
| 살아난 환자의 24시간 구간 | 원저자 코드는 무작위라 매번 달라짐 — 우리는 다시 돌려도 같게 고정 |
| 지식 규칙이 만들어진 과정 (가이드라인 → 지식 그래프 → 규칙 찾기) | 공개 코드에서 이 과정이 학습과 이어져 있지 않음. 학습에 쓰는 규칙은 코드에 직접 적혀 있어서, 그 규칙만 그대로 씀 |
| 논문 Table 2 (전체 예측을 모아 신뢰구간 계산) | 원저자 계산 코드가 공개되지 않음 |
