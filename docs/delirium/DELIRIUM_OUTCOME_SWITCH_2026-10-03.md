## 설계

- **결과를 교체했다**: 섬망 발생(24h 내 CAM 양성) → **원내 사망** 과 **앵커 후 7일 내 사망**.
- **섬망은 중간 개념(mediator)** 이다. CAM-ICU 라벨은 섬망 헤드의 지도 신호로만 쓰고, 출력은 사망이다.
  공리 구조: 위험인자(진정·통증·거동·나이·동반질환) → Delirium → Death.
- 결과 라벨이 사망이라 **섬망 라벨이 없는 앵커(29%)도 평가에 들어간다** — 23_ 에서 버려야 했던 구간이 살아난다.
- `Delirium → Death` 는 2018 PADIS 원문이 뒷받침하지 않으므로(`KG_PADIS_FOLLOWUP_2026-09-23.md` §1) 출처 등급을 `external` 로 따로 뒀다.

### 읽는 법

1. **결과를 임상 결과로 바꿔도 공리는 성능을 올리지 않는다.** 섬망→사망 공리를 넣은 5b − 공리 없는 4m = **+0.1 (원내)** · **−0.1 (7일)**, 시드 SD 0.5~0.8 안이다. 가중치를 0.5 로 올려도 같다.
2. **개념 병목 자체가 비용이다.** BiLSTM 83.4 → CBM 82.4 (원내), 90.3 → 86.5 (7일). 7일 사망에서 비용이 훨씬 크다 — 사망 임박 신호(활력징후 추세)가 PADIS 개념 15개로 압축되지 않는다.
3. **섬망을 중간 개념으로 넣는 것은 병목 손실을 조금 메운다**: 4c → 4m +0.5 (원내) · +0.3 (7일). 공리보다 **mediator 지도 신호**가 더 기여한다.
4. **외부검증(2020–22)에서 순서가 바뀌지 않는다.** 원내 사망에서 4m 이 83.6 으로 가장 높지만 차이는 0.3 이하다.
5. XGB 는 7일 사망에서 특히 강하다(91.6 vs BiLSTM 90.3) — 섬망 예측(47.8 vs 45.4)·sepsis 사망 재현과 같은 방향이다.

## 3. KG 범위별 공리 (교수님 피드백 ②)

추출 조건별/중복 트리플로 KG 를 만들고, 실행 가능한 공리만 컴파일해 같은 분할로 학습했다 (결과 = 원내 사망).

| H 사람이 만든 KG | 20 | 13 | 0 | 4 | 82.9 | 0.69 | 59.9 |

술어 처리: `increasesRiskOf` → 함축 · `decreasesRiskOf` → 머리 부정 · `associatedWith` → 가중치 low · `hasNoEffectOn` → 공리로 만들지 않고 **같은 쌍의 공리를 기각** · `precludes` → 평가 불능 가드.

### 읽는 법

1. **공리를 많이 넣는 쪽이 낫지 않다.** 공리 6개(합의 KG)가 15개(합집합)보다 높다(83.1 vs 82.9). 차이는 SD 안이라 "같다"가 정확하지만, **적어도 많을수록 좋아지지는 않는다.**
2. **자동 추출 KG 가 사람이 만든 KG 보다 낮지 않다** (83.1 / 83.0 vs 82.9). 추출 품질이 아니라 **공리가 결과로 이어지는 경로**가 성능을 가른다는 앞선 결론과 일관된다.
3. **미매핑이 가장 큰 손실이다.** 추출 트리플의 절반 이상이 공리가 되지 못한다 — 억제대·기계환기·오피오이드·성별·멜라토닌이 MIMIC 변수로 매핑되지 않았다(합의 KG 25개 중 13개 탈락).
4. 사람 KG 는 미매핑이 4개뿐이다 — **사람이 처음부터 "데이터에 있는 개념"만 골랐기 때문**이다. 자동 추출은 원문에 있는 것을 다 가져오므로 실행 가능성 필터가 따로 필요하다.

## 4. 공리별 만족도 (낮은 쪽 = 모델이 어기는 규칙)

| 공리 | 만족도 |
|---|---:|
| 고혈압 → 섬망 | 0.50 |
| 심한 통증 → 섬망 | 0.52 |
| 고령 → 섬망 | 0.54 |
| 진정 강도 → 사망 | 0.69 |
| 덱스메데토미딘 → ¬섬망 | 0.77 |
| 외상·치매·수혈 → 섬망 | 0.94~0.97 |

- 활성화율이 높은 공리(고령·고혈압)의 만족도가 낮고, 드문 공리(외상·치매·수혈)가 높다.
  > ⚠️ 이것을 "흔한 위험인자의 공리가 임상적으로 더 부실하다"로 읽지 않는다. 만족도 `1 − a + a·b` 는
  > 앞부분 a 가 자주 켜질수록 낮아지므로, 이 순서는 **활성화율이 만들어 내는 기계적 결과**다.
  > 공리별 타당성 판단은 활성화 환자군의 실제 결과 발생률로 따로 해야 한다(감사 표).
- 만족도가 높은 공리는 모델이 이미 맞추고 있어 **학습 신호로서 기여가 작다**는 점만 남는다.

## 4-1. 이 실험의 범위 (2026-10-08 추가)

**공리는 사망용으로 바꾸지 않았다.** 타깃만 섬망 → 사망으로 옮기고 공리 집합(`AX_RISK`, 머리 = Delirium)은
그대로 두었다. 그래서 사망 출력을 가리키는 공리는 5a 에서 **0개**, 5b·5c 에서 1개, 5d 에서 3개다.
→ 이 결과로 "타깃 선택이 원인이 아니다"라고 말할 수 없다. 말할 수 있는 것은
"섬망 중간 개념 + 중개 공리를 붙여도 사망 예측은 좋아지지 않는다" 까지다.
공리를 사망으로 재타깃한 비교는 `eda/41_retarget_axioms.py`, 목표를 섬망으로 맞춘 논문식 손실 비교는
`eda/40_ltn_paper_loss_delirium.py` 에서 따로 한다.
