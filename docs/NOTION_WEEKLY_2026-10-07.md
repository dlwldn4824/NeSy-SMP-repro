## 요약 3줄

1. **지식 공리는 "성능에 도움이 안 되는" 것이 아니라 "학습에 전달되지 않는" 상태였습니다.** 머리를 무작위로 섞은 **가짜 공리와 진짜 공리의 성능 차이가 +0.01**이고, 공리 12개 중 11개는 사망 예측에 대한 **기울기가 정확히 0**입니다.
2. 교수님 피드백 3건(겹침 계산 · KG 범위별 공리 · 예측 대상 변경)을 모두 실행했습니다. 겹침은 one-shot ∩ few-shot **31개(Jaccard 0.84)**이고, KG 범위·결과 종류를 바꿔도 공리 효과는 편차 안입니다.
3. 그래서 **공개 코드에 빠져 있던 사망 연결 5개를 직접 추가해** 돌렸습니다. 1회차 결과는 NeSy−LTN **+0.05**(판정선 +0.3 미달), F1은 −0.30입니다. 2회차가 내일 오후 끝나면 판정이 확정됩니다.

## 1. 교수님 피드백 대응

| 피드백 | 한 일 | 결과 |
|---|---|---|
| 재현은 저자와 직접 확인 | 문의 항목 정리 (제외 기준 정의 · 임계값 출처 · 공개 코드와 실제 코드 차이) | `docs/AUTHOR_QUESTIONS.md` — 메일 발송만 남음 |
| **one-shot / few-shot 겹침은?** | PADIS·sepsis 양쪽 계산 | PADIS: one 35 · few 33 중 **31개 겹침(0.84)** · 세 조건 공통 25 |
| **각각·중복으로 KG 만들어 공리 뽑기** | KG 6종(합의·조건별·합집합·사람) 컴파일 → 같은 분할로 학습 | 전부 기준선 ±0.4 안 · **공리 많을수록 좋아지지 않음** |
| **예측 대상을 임상 결과로** | 섬망 → **원내 사망 · 7일 내 사망**으로 교체, 섬망은 중간 개념 | 공리 효과 +0.1 / −0.1 (편차 안) |
| 섬망에서 NeSy 기여 가능성 | 성능 · 도메인 이동 · 설명 세 갈래로 분해 검증 | 성능·도메인 이동은 이득 없음 · **설명 지표는 산출물로 가치 있음** (§5) |

**예시 개수에 대한 관찰**: 예시는 *무엇이 뽑히는지*가 아니라 **관계명 표기**를 바꿉니다. 원문이 "associated with"(연관)라고 쓴 것을 예시를 보면 정답 형식인 `increasesRiskOf`(위험 증가)로 바꿔 씁니다. 그래서 정답 기준 점수는 7/14 → 10/14로 오르지만, 근거 판정(Y)은 57% → 38~50%로 내려갑니다.

## 2. 이번 주 핵심 발견 — 공리가 전달되지 않는다

### 2-1. 음성 대조군 (섬망 코호트, 결과 = 원내 사망, 10 epoch · 시드 3)

| 조건 | AUROC |
|---|---:|
| 기준선 (공리 없음) | **82.88** |
| 진짜 공리 (w=0.2) | 82.77 |
| **가짜 공리 (머리 무작위)** | 82.76 |
| 진짜 공리 w=1.0 | 82.61 |
| 진짜 공리 w=2.0 | 82.58 |
| 진짜 공리 최악위반 집계 w=1.0 | 81.65 |

- **진짜 − 가짜 = +0.01.** 공리가 의미 있게 작동하면 가짜 공리는 성능을 떨어뜨려야 합니다.
- 가중치를 10배 올리면 **오히려 나빠집니다**(−0.19 ~ −1.23).

### 2-2. 기울기 확인 — 경로 자체가 없음

공리 손실만 따로 역전파해 파라미터별 기울기를 측정했습니다.

| 공리 | 사망 로짓에 대한 기울기 |
|---|---:|
| 위험인자 → 섬망 (11개) | **0.000000** (전부) |
| 섬망 → 사망 (1개) | 0.0028 |

| 손실 | 사망 출력층 기울기 |
|---|---:|
| 과제 손실 (사망 BCE) | 0.726 |
| 공리 손실 × w=0.2 | 0.003 (**0.4%**) |

결과가 섬망인 공리는 사망 출력층을 거치지 않으므로 **구조상 영향을 줄 수 없습니다.**

## 3. 공개 코드에 빠진 연결을 추가해 돌린 실험 (sepsis 6h)

원본 코드의 지식 공리는 두 단계입니다. ① 앵커(임계 넘는 환자에게 위험 술어를 참으로) ② 함축(위험이면 사망).
**②가 8개뿐이고, GCS · 수축기혈압 · 호흡수 · 크레아티닌 · 혈당은 ①만 있습니다.** 결측 0 채우기로 잘못 켜지던 규칙이 모두 여기 속해, 결측 수정(민감도 A)의 효과가 0이었던 원인으로 봅니다.

**한 일**: 함축 5개 추가(S3) + 혈당 버그 수정(S4, 함수 객체를 1과 비교해 공리가 항상 비어 있던 것) + 결측 처리 수정(S1) 동시 적용. 같은 설정 2회 실행.

| 조건 | NeSy | LTN | **차이** | F1 차이 |
|---|---:|---:|---:|---:|
| 원본 1회차 | 91.02 | 91.27 | −0.25 | −0.09 |
| 원본 2회차 (같은 코드 재실행) | 91.14 | 91.21 | −0.07 | −0.02 |
| 결측 수정만 (S1) | 91.17 | 91.23 | −0.06 | −0.30 |
| **연결 5개 + 혈당 수정 (r1)** | **91.18** | 91.14 | **+0.05** | −0.30 |

- 부호는 처음으로 양수가 됐지만 **판정선 +0.3에 못 미치고**, fold별 변동(−0.29 ~ +0.24)이 평균보다 큽니다.
- F1은 −0.30으로 오히려 낮습니다.
- 새 함축의 만족도가 낮습니다: **혈당 0.55** · 크레아티닌 0.68 · GCS 0.69 (기존 함축 평균 0.80). 혈당은 입원의 80%에서 켜지는데 실제 사망률은 15%라 데이터와 충돌합니다.
- 패치 검증: 규칙 켜짐 비율이 의도값과 일치(GCS 27.6% · 혈압 71.0% · 크레아티닌 26.9% · 혈당 79.9%), XGBoost·RF는 원본과 소수점까지 동일.

**2회차는 10/7 오후 완료 예정이고, 혈당 함축만 뺀 변형(함축 4개)은 10/8 예정입니다.**

## 4. 그 밖에 돌린 실험

| 실험 | 결과 |
|---|---|
| **결과를 임상 결과로 교체** (섬망 → 원내 사망·7일 사망, 섬망은 중간 개념) | XGB 84.0 > BiLSTM 83.4 > CBM+mediator 82.9 ≈ LTN 82.8. 공리 효과 +0.1 / −0.1 |
| **KG 범위별 공리** (합의 25 / 조건별 / 합집합 44 / 사람 20) | 공리 6~16개, 전부 기준선 ±0.4 안. 자동 추출 KG가 사람 KG보다 낮지 않음 |
| **미매핑 개념 회수** (억제대·기계환기·오피오이드·멜라토닌) | 공리 1~2개씩 증가, 결론 불변. 멜라토닌은 창 안 기록이 거의 없음 |
| **연도 도메인 이동** (2008–16 학습 → 2020–22 평가) | 공리 모델의 내외부 격차가 공리 없는 모델과 동일 (−2.00 vs −2.01) |
| **sepsis + PADIS 변수** (진정·통증·거동·억제대·진정제 추가) | 모든 모델 +0.7~1.1 (6h·12h·24h). **향상은 변수에서 왔고 공리에서 오지 않음** |
| **구조 가설 3개** | §5 |

## 5. 구조를 바꿨을 때 — 그리고 설명 지표로서의 가치

**(가) 공리 경로를 좁히면 공리가 전달되기 시작하지만 성능이 떨어집니다.**

| 구조 | 공리 없음 | 진짜 | 가짜 | 진짜−가짜 |
|---|---:|---:|---:|---:|
| 현재 구조 | 81.60 | 81.55 | 81.59 | −0.04 |
| 섬망만 통과 | 75.04 | 75.21 | 74.83 | **+0.38** |
| 2단계 학습 (섬망 고정 후 사망) | 46.32 | 48.70 | 48.06 | **+0.64** |

**(나) 추론 시 제약으로 걸면 약하게만 이득이고, 강하게 걸면 급락합니다** (λ=0.1에서 +0.17, λ=1.0에서 −6.2).

**(다) 공리 만족도는 성능과 무관하게 임상적으로 읽을 수 있는 산출물입니다.**

| 공리 | 켜진 환자 | 켜진 환자 사망률 (전체 21.2%) |
|---|---:|---:|
| 깊은 진정 → 섬망 | 18.9% | **52.9%** |
| 진정 강도 → 섬망 | 27.4% | 45.4% |
| 섬망 → 사망 | 38.5% | 39.2% |
| 조기 거동 → ¬섬망 | 24.1% | **4.4%** |
| 고혈압 → 섬망 | 70.5% | 21.6% (차이 없음) |

→ 성능 1위가 아니어도 **"어떤 규칙이 실제로 위험층을 가려내는가"**는 보고할 수 있는 결과입니다. 반대로 고혈압 규칙처럼 70%에게 켜지면서 사망률 차이가 없는 규칙은 KG에서 재검토 대상입니다.

## 7. 교수님께 확인·결정 부탁드릴 것

1. **저자 문의 메일** — 항목 정리 완료(`AUTHOR_QUESTIONS.md`). 핵심 3개: ① "분석에 필요한 데이터 없음" 제외 기준의 정의 ② 공리 임계값(CRP 100 · 백혈구 30 · 혈당 100)의 출처 ③ 공개 코드가 그대로 실행되지 않는 점(RF·XGBoost 입력 계산에서 첫 fold 중단)과 실제 사용 코드의 차이.
2. **논문 방향** — 지금 증거로는 ① "기존 NeSy 구조의 한계를 음성 대조군으로 입증한 부정 결과" 또는 ② "공리가 작동하려면 어떤 구조·내용이어야 하는가"로 전환하는 두 갈래입니다. 어느 쪽으로 쓸지 결정이 필요합니다.
3. **PADIS KG 승인** — `섬망 → 사망`은 2018 PADIS 원문이 뒷받침하지 않습니다(전수 검색 확인). 규칙에서 제외할지, 출처를 가이드라인 밖 문헌으로 바꿀지 판단이 필요합니다.
4. **다음 실험 우선순위** — 연결해도 효과가 없다면, 다음은 **공리 내용을 코호트에서 재추정**(임계값·방향을 데이터로 다시 뽑아 KG에 반영)하는 쪽을 제안합니다.
