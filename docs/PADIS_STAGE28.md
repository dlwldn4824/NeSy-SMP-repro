## 3. B — 6단계 LNN

구현: 가중 Łukasiewicz 함축 `a→b = clamp(w_a(1−a) + w_b·b)` 의 하향 추론 경계. 규칙 진리 하한 = GRADE 가중.
규칙 가중치는 실제 라벨과의 모순으로만 학습, 모델은 경계 밖 예측에만 벌점. '전부 UTA' 앵커 60,537건(12.4%)은 라벨 구간 [0,1].
IBM `lnn` 라이브러리가 아니라 이 식을 직접 구현한 최소판이다.

- **성능이 떨어진다**: 라벨만 42.7 (CBM −0.5) · +전부 UTA **42.2 (−1.0)**.
- **'전부 UTA' 앵커 자체에서도 이득이 없다** — 72h 안 확정 기록이 생긴 6,805건의 지연 라벨로 점검하면
  AUROC CBM 74.1 · LNN 라벨만 73.8 · **LNN +전부 UTA 72.7** (가장 낮음). 구간 진리값으로 넣은 앵커를 오히려 못 맞춘다.
- 왜: 규칙 하한 평균 0.37 인데 모델 예측의 57~60% 가 하한 아래다 — **규칙이 개별 환자 수준에서 데이터와 맞지 않는다**
  (예: Benzo 노출자의 섬망 55.6%). 데이터가 규칙 가중치를 1 → 1.4~2.2 로 키워 규칙을 약하게 만들었고,
  남은 하한이 예측을 위로 밀어 **calibration 이 가장 나빠졌다** (N 앵커 ECE 6.3~7.7 · 평균 예측 18~20% vs 기저 12.0%).
- → **사전 게이트("4단계 ≈ 5단계면 LNN 은 과잉")에 더해, 직접 돌려봐도 구간 진리값이 도움이 안 된다.** 접는 것을 권한다.

## 4. C — Assessable 보조출력 재실험

- 기존 방식(미관찰을 같은 배치에 섞기): 43.5 ± 0.3 (CBM +0.3)
- 균형 배치(라벨 배치 유지 + 미관찰 1/4 배치, Assessable 손실만): w1 42.9 · w.3 43.1 (−0.3 · −0.2)
- **어느 쪽도 SD 범위 안** — 재활용해도 이득·손해가 없다. 과거 "−3.9" 는 당시 개념 세트(개념 5종 등)에서 나온 값으로 보이며 현재 설정에서는 재현되지 않는다.

## 6. 결정에 주는 것

1. **LNN(6단계) 접기** — 게이트 발동 + 실측으로도 손해. 교수님 질문 4의 답.
2. **논리층의 역할은 '성능'이 아니라 '정합성'으로 확정** — 검수본에서도 같다(Benzo 0.59 → 0.79).
3. **Dexmed 규칙은 데이터와 반대** — 충돌 해소 정책에서 '비교형 유지 + 교란 주석' 또는 '공리 제외' 중 결정 필요.
