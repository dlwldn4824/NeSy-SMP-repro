## 2. 읽는 법

1. **앵커 공리 10개는 사망 모델에 gradient 가 정확히 0 이다.** 머리가 위험 술어이므로 구조적으로 당연하다.
   앵커는 위험 술어 MLP 만 학습시킨다.
2. **함축 공리 8개는 모두 사망 모델로 흐른다** (0.42~0.48). 크기도 데이터 공리(0.225)와 같은 자릿수다.
3. 논문 가중치(데이터 0.8 · 지식 0.2)를 적용하면 사망 모델 파라미터가 받는 신호의 **약 17%** 가 지식에서 온다.

> **섬망 쪽 결과와 다르다.** 우리 섬망 실험(eda/38)에서는 공리 12개 중 11개가 머리가 `Delirium` 이라
> 사망 로짓 gradient 가 0 이었고, 공리 항의 몫이 과제 손실의 **0.4%** 였다. 원저자 코드는 그렇지 않다 —
> **함축 공리가 사망 술어를 직접 가리키므로 경로가 살아 있다.**
>
> 따라서 "공리가 학습 목표까지 전달되지 않는다"는 진단은 **우리 섬망 설정에 한정된 설명**이고,
> 패혈증 재현에서 NeSy 가 LTN 을 넘지 못하는 이유로는 쓸 수 없다. 패혈증 쪽은 경로가 있는데도
> 효과가 없으므로, 남는 설명은 **공리가 데이터 위에서 추가 정보를 주지 못한다**(또는 앵커 술어가
> 그 정보를 흡수한다) 쪽이다.

## 3. 한계

- **위험 술어 MLP 는 원본 코드가 저장하지 않는다**(`torch.save(lstm.state_dict())` 뿐). 그래서 술어는
  같은 구조로 새로 초기화한 상태에서 쟀다. **0 / 비0 (경로가 있느냐) 판정은 정확**하지만, 크기는
  "학습 종료 시점" 값이 아니라 **초기값 근처에서의 크기**다. 만족도가 0.47~0.69 로 0.5 주변에 몰려 있는 것이
  그 증거다(학습된 술어라면 더 뾰족해진다). 시드를 바꿔 다시 재면 크기의 흔들림을 볼 수 있다(`--seed-pred`).
- fold 1 · 배치 20개 평균이다.
- 앵커 13개 중 **10개만** 측정됐다. 혈당 앵커는 코드 버그로 항상 비어 있고(함수 객체를 `1` 과 비교),
  크레아티닌·호흡수·수축기혈압 앵커는 결측 0 채움 때문에 조건이 성립하지 않는다 —
  이미 보고한 "13개 규칙 중 6개 오작동"과 같은 현상이다.
- 감사는 같은 입력에 같은 값이 나와야 하므로 드롭아웃을 끈 eval 모드로 쟀고, cuDNN LSTM 이
  eval 모드 backward 를 막아 cuDNN 을 끈 상태로 계산했다(수치는 동일, 속도만 느리다).
