## 해석

1. **0.09% 의 기록 오류가 딥러닝 계열 AUC 를 1~2점 깎고 있었다.** 변화 폭(+1.0~1.9)이 같은 코드 재실행 편차(±0.1~0.3)보다 훨씬 크다. 트리 모델(XGBoost·RF)은 +0.2 로 거의 그대로.
   - 딥러닝 입력은 변수별 MinMax 정규화라, 최댓값 하나(예: 수축기혈압 119,119)가 나머지 값을 0 근처로 눌러 버린다. 트리 모델은 순서만 보므로 영향이 작다.
2. **XGBoost 와의 차이가 줄었다.** AUC 차이 XGBoost − NeSy-SMP: 1.53~1.65 → **0.58**. XGBoost 가 여전히 5 fold 모두 1등 (fold 4·5 는 0.07~0.08 차이).
3. **F1 은 순위가 바뀌었다** — LTN 82.80 · NeSy-SMP 82.79 > BiLSTM 82.14 > XGBoost 81.81. 논문도 F1·정확도에서 NeSy-SMP 가 1등이었다.
4. **그래도 규칙(NeSy-SMP)과 규칙 없음(LTN)은 같다** (AUC 92.27 = 92.27, F1 82.79 vs 82.80). 성능 향상은 규칙이 아니라 **데이터 정제**에서 왔다.
   → 논문 결과와의 차이 중 "XGBoost 가 크게 이긴다"는 부분은 **입력 데이터 품질 문제**로 상당 부분 설명된다. "지식 규칙이 성능을 올린다"는 주장은 여전히 재현되지 않는다.
