# 주간 정리 (2026-10-03 ~ 10-06)

교수님 피드백 3건에 대한 대응으로 시작해서, **"지식 공리가 왜 효과가 없는지"를 음성 대조군으로 확정**한 주였다.

---

## 0. 한 줄 요약

**공리는 "도움이 안 되는" 것이 아니라 "작동 자체를 안 하고" 있었다.** 머리를 무작위로 섞은 가짜 공리와 진짜 공리의 성능 차이가 +0.01 AUROC 다.
결과를 임상 결과(사망)로 바꾸고, KG 범위를 바꾸고, 미매핑 개념을 회수하고, 가중치를 10배 올리고, 도메인 이동으로 평가해도 결론이 바뀌지 않았다.
남은 가설은 **구조**(공리 손실이 결과 예측 경로로 흐르지 않는다)이고, 그 세 가지 검증이 지금 돌고 있다.

## 2. 돌린 실험 (7건)

| # | 실험 | 결과 |
|---|---|---|
| 1 | **안 1** 결과를 원내 사망·7일 사망으로 교체 (섬망 = 중간 개념) | 공리 효과 +0.1 / −0.1 (SD 0.5~0.8 안) |
| 2 | **KG 범위별 공리** (합의 25 / 조건별 / 합집합 44 / 사람 20) | 전부 기준선 ±0.4 안. 공리 많을수록 좋아지지 않음 |
| 3 | **음성 대조군** (가짜 공리) + 가중치 0.2~2.0 + 최악위반 집계 | **진짜 − 가짜 = +0.01.** 가중치 올리면 오히려 −0.2 ~ −1.2 |
| 4 | **미매핑 개념 회수** (억제대·기계환기·오피오이드·멜라토닌) | 공리 1~2개씩 증가, 결론 불변. 멜라토닌은 기록 거의 없음 |
| 5 | **연도 도메인 이동** (2008–16 학습 → 2020–22 평가) | 공리 모델의 내외부 격차가 공리 없는 모델과 동일 |
| 6 | **안 2** sepsis 사망 예측에 PADIS 변수 추가 (6h·12h 완료, 24h 진행) | 모든 모델 +0.7~1.1, NeSy ≈ LTN 그대로 |
| 7 | 운영 지표 (고정 특이도 88·90% 민감도) | 순위 동일 — AUROC 와 같은 그림 |

### 2-1. 안 1 — 결과를 임상 결과로 (10 epoch · 시드 3)

| 모델 | 원내 사망 AUROC | 7일 내 사망 AUROC |
|---|---:|---:|
| XGB | **84.0** | **91.6** |
| BiLSTM | 83.4 | 90.3 |
| CBM | 82.4 | 86.5 |
| CBM + 섬망 mediator | 82.9 | 86.8 |
| LTN + 섬망→사망 | 82.8 | 86.7 |

개념 병목이 비용(−1.0 / −3.8)이고, 섬망 중간 개념이 그 일부를 메운다(+0.5 / +0.3). 공리 자체는 효과 없음.

### 2-2. 음성 대조군 — 핵심

| 변형 | AUROC |
|---|---:|
| 기준선 (공리 없음) | **82.88** |
| 진짜 공리 w=0.2 | 82.77 |
| 가짜 공리 (머리 무작위) | 82.76 |
| 진짜 공리 w=2.0 | 82.58 |
| 진짜 공리 최악위반 w=1.0 | 81.65 |

1 epoch 에서는 가중치를 올리는 쪽이 좋아 보였는데(정규화 효과), 10 epoch 에서 완전히 뒤집혔다.

### 2-3. 안 2 — sepsis + PADIS 변수 (6h·12h)

| 시점 | 모델 | 논문 조건 AUC | **+PADIS 변수** | F1 (논문 조건 → +PADIS) |
|---|---|---:|---:|---|
| 6h | XGB | 92.67 | **93.33** | 81.72 → 82.94 |
| | LTN | 91.27 | 91.99 | 81.74 → 83.57 |
| | NeSy-SMP | 91.02 | 92.11 | 81.66 → **83.58** |
| 12h | XGB | 91.81 | **92.59** | 80.41 → 81.30 |
| | LTN | 89.78 | 90.73 | 79.64 → 80.91 |
| | NeSy-SMP | 89.92 | 90.83 | 79.73 → 81.28 |

진정·통증·거동·억제대·진정제 변수를 넣으면 **모든 모델이 +0.7~1.1** 오른다. F1 에서는 LTN·NeSy 가 XGB 보다 높다.
**NeSy − LTN 은 6h +0.12 · 12h +0.10 으로 여전히 편차 안이다** — 향상은 변수에서 왔고 공리에서 오지 않았다.
