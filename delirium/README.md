# delirium/ — 섬망 코호트 파이프라인

번호는 **실행 순서**다. 한 줄기의 파이프라인이므로 중간 번호만 따로 돌리면 입력이 없다.
(2026-10-11 에 `eda/` 에서 이름을 바꿨다. 폴더 안이 데이터 탐색이 아니라 학습·공리 실험이라
이름이 내용과 맞지 않았고, `docs/delirium/` 규칙과도 맞추기 위해서다.)

| 번호 | 단계 | 내용 |
|---|---|---|
| 00 ~ 09 | 추출·탐색 | MIMIC 추출, 코호트 정의, 라벨 스캔·생성, DB 재고 확인 |
| 10 ~ 21 | 설계 | 창(window) 설계, 시간 분할, 조기 거동·진정제 상세, 분할 명세, 검열 사유 |
| 22 ~ 28 | 모델 | 2단계 XGB, 3·4단계 BiLSTM + 개념 병목, 앵커 히스토리, 그림, PADIS 계획 |
| 29 ~ 34 | 결과·KG | 예측 대상 교체(사망), KG 범위별 공리, 음성 대조군, 개념 회수, 연도 도메인 이동 |
| 35 ~ 41 | 공리 진단 | 구조 가설, 추론 시 제약 투영, 공리 감사, gradient 경로, 논문식 손실, 공리 재타깃 |

## 스크립트 사이 의존

- `29_outcome_mortality.py` 는 `23_stage34_bilstm_cbm.py` 의 앞부분을 `exec` 한다.
- `30 ~ 41` 은 `29_outcome_mortality.py` 의 앞부분을 `exec` 한다.

모두 **같은 폴더 기준 상대 참조**라, 파일을 다른 폴더로 옮기면 깨진다.

## 환경변수

| 변수 | 뜻 | 기본 |
|---|---|---|
| `EDA_DATA` | 추출해 둔 중간 테이블 캐시 | `notes/eda` |
| `EDA_OUT` | 결과 저장 폴더 | `C:\data\padis_eda_out` |
| `MIMIC_DB` · `EDA_SQLITE` | MIMIC-IV SQLite 경로 | — |

`EDA_DATA`/`EDA_OUT` 과 `notes/eda` 는 **이름을 그대로 두었다.** 이미 만들어진 캐시·결과
폴더를 가리키고 있어서 바꾸면 돌아간 결과를 다시 찾아야 한다. 안에 든 것은 탐색 산출물이
아니라 **추출 테이블 캐시**다.
